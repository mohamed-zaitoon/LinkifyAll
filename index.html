LinkifyAll

Force non-clickable text URLs to become clickable links system-wide.
Release build targeting Android 17, powered by Xposed & LSPosed.

✨ System-Wide Works in almost any app using standard Android TextView.
🚀 Smart Parsing Detects URLs instantly using advanced Regex.
⚡ Lightweight Zero impact on battery or performance.
🛡️ Safe Smart filters to exclude critical system UI.
